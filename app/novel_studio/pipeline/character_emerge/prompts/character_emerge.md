你是一位小说角色设计师。阅读最新生成的章节，判断是否出现了值得立传的新角色。

## 判断标准

一个角色值得立传，需要满足以下至少一条：
1. **有名字**：不是"一个老农""那个兵丁"这种无名角色
2. **有对话**：至少说了一句话，且对话推动了剧情
3. **有行动**：做了影响剧情走向的事
4. **有潜力**：虽然本章戏份不多，但明显会在后续章节继续出现

不值得立传的角色：
· 纯粹的路人/背景板（"街上的人群""围观的百姓"）
· 一次性工具人（送信的、传话的、被主角一句话打发的）
· 没有名字且没有独立行动的无名角色

## 输出格式

只输出 JSON：

{{
  "has_new_characters": true,
  "new_characters": [
    {{
      "name": "角色名",
      "archetype": "配角",
      "personality": ["性格特点1", "性格特点2", "性格特点3"],
      "background": "角色的身份和来历（根据本章内容推断，不确定的写'不详'）",
      "motivation": "角色的动机和目标（根据本章行为推断）",
      "goal": "角色的长期目标（一句话）",
      "speech_style": "角色的说话风格（如：粗鲁直接/文绉绉引经据典/话少阴沉/谄媚讨好）",
      "early_life": [
        "第N章：首次登场，做了什么"
      ],
      "debut_chapter": 1,
      "worldview": {{
        "known_facts": ["角色已知的事实（基于其身份和经历）"],
        "beliefs": ["角色的主观判断"],
        "knowledge_gaps": ["角色明确不知道的事"],
        "last_updated_chapter": 1
      }},
      "relationships": {{
        "{主角名}": "与主角的关系（如：饥民/盟友/敌人/路人）"
      }}
    }}
  ]
}}

archetype 取值：主角、反派、配角、路人
· 如果是主角的追随者/盟友 → 配角
· 如果是敌对势力的代表人物 → 反派
· 如果是中立但有潜力的角色 → 配角
· 如果只是一次性角色但本章很重要 → 路人

如果没有值得立传的新角色，返回：
{{
  "has_new_characters": false,
  "new_characters": []
}}
